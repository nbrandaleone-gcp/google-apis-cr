Method Name Input Parameters Output Primary Responsibility
parse json_str : String ServiceModel Parses raw Discovery JSON into the complete in-memory typed AST model.
crystal_type_for prop : JSON::Any String Maps discovery types ($ref, string, integer, array, object) to Crystal type strings.
container_type_for type : String, prop : JSON::Any String Resolves nested Array(T) element types and Hash(String, T) dictionaries.
sanitize_identifier name : String String Converts names to snake_case and appends _param if colliding with Crystal keywords.
collect_resources resources, schemas, prefix Array(ResourceModel) Recursively discovers nested endpoints and extracts method definitions.
parse_method_parameters method_json : JSON::Any Array(ParameterModel) Sorts required path parameters before optional query parameters.
generate service : ServiceModel, target_dir : String Nil Renders types.cr, *_service.cr, client.cr, vX.cr, README.md, and runs crystal tool format.
generate_spec service : ServiceModel, spec_dir : String String Generates spec test file verifying client instantiation and base_url.
generate_sample_cli service : ServiceModel, project_root : String Tuple(String, String?) Generates src/bin/list_*.cr, registers in shard.yml and google_apis_cr.cr, and runs crystal build.
pick_primary_list_resource service : ServiceModel Tuple(ResourceModel, MethodModel)? Scores resource listing endpoints to pick the best candidate for the sample CLI tool.
ensure_shard_target project_root, target_name, main_path Nil Idempotently injects compilation target into shard.yml under targets:.
ensure_main_require project_root, service Nil Idempotently appends service require statement to src/google_apis_cr.cr.
